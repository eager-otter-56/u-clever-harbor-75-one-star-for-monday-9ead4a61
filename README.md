# One Star for Monday

A one-star review of Monday, written as if Monday were a restaurant: you arrive at nine, leave at five, and somehow the waiter bills you for all five days. One tight mechanism, concrete numbers, and the turn lands in the final clause — a complaint that could only be about Monday, the first day of five.

The entry program (`main.py`) writes the single-line review to `entry.txt` in `MAKEFUN_OUTPUT_DIR` (default `/output`).
